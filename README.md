# 🌲 The Hidden Woods

> *탐험을 하며 만난 적을 카드 구성으로 쓰러트리고 다음 스테이지로 넘어가는 게임*

<br>

## 📖 시놉시스

깊은 숲을 돌아다니던 **A**는 신비한 제단과 조우하며 어떤 힘을 각성하게 된다.
그림이 그려진 카드를 통해 특별한 능력을 쓸 수 있게 된 A, 정신을 차리고 보니 주변은 평범한 숲이 아니게 되었고 동물들마저 난폭하게 공격해오기 시작했다.

**이들에게서 살아남아 숲을 빠져나가는 것이 A의 목표.**

<br>

## 🎮 게임 장르

| 장르 | 설명 |
|------|------|
| 턴제 / 슈팅 | 전투 시 탄환이 발사되는 슈팅 연출 포함 |
| 퍼즐 덱빌딩 | 카드를 조합해 퍼즐 오브젝트를 활성화 |
| 로그라이크 / 생존 | 매 플레이마다 달라지는 카드 및 보상 |
| 탑다운 | 위에서 내려다보는 시점의 2D 맵 탐험 |

<br>

## 🕹️ 핵심 게임플레이

```
게임 시작
    │
    ▼
맵 탐험 (이동 / 아이템 획득 / 트랩 회피)
    │
    ▼
적과 조우 ──→ 전투 씬 전환
    │               │
    │         카드 3장 공개 → 1장 선택 → 공격 발사
    │               │
    │         적의 턴 → 다음 행동 패턴 UI 표시
    │               │
    │         반복 → 승패 결정
    │
    ▼
전투 승리 → 보상 획득 (카드 / 아이템)
    │
    ▼
다음 스테이지 입구 상호작용 → 스테이지 이동
```

<br>

## ⚔️ 전투 규칙

- 게임 시작 시 플레이어는 **12장의 카드**를 보유
- 적과 조우하면 **3장의 카드**가 공개되고 그 중 **1장을 선택**
- 선택한 카드로 공격 또는 효과 발동 → **플레이어 턴 종료**
- 이후 적이 공격 또는 효과 발동 → **적 턴 종료**
- 적의 **다음 행동 패턴을 미리 확인**하여 전략적 선택 가능
- 카드를 모두 소진했음에도 적의 체력이 남아 있으면 **패배**

<br>

## 📋 클리어 / 실패 조건

✅ **클리어** : 적의 체력이 플레이어보다 먼저 0이 되면 **승리**

❌ **실패 조건**
- 플레이어의 체력이 먼저 0이 되면 **패배**
- 소지한 카드를 전부 사용했음에도 적의 체력이 남아 있으면 **패배**

<br>

## 🗂️ 사용 자료구조

| 자료구조 | 사용 위치 |
|---------|----------|
| `List` | 플레이어가 소지하고 있는 카드 목록 |
| `Array` | 전투 시 선택 카드 슬롯 수 / 적의 다음 행동 표시 슬롯 수 |
| `Stack` | 중첩 효과 카드 처리 / 선택 카드 취소(Undo) 기능 |
| `Queue` | 적의 행동 패턴 순서 관리 / 맵 적 스폰 순서 관리 |
| `Dictionary` | 전체 카드 종류 ID와 설명 매핑 |

<br>

## 🖥️ UI 구성

### 인게임 화면
- 플레이어 체력
- 소지 카드 목록
- 메뉴 버튼 (설정 / 종료 / 카드 확인)

### 전투 화면
- 플레이어 / 적 체력
- 선택 가능한 카드 3장
- 남은 카드 수
- 적의 다음 행동 패턴

### 기타 화면
- 전투 결과 및 보상 화면
- 게임 저장 / 종료 UI

<br>

## ✅ 구현 우선순위

### 필수 구현
1. 플레이어 이동
2. 적 배치 및 조우
3. 카드 배틀 시스템

### 추가 구현 (여유 시)
1. 카드 도감
2. 추가 아이템 종류 확장
